FAQ

O NotiKeep consegue ver notificações recebidas antes de instalá-lo?

Não. O NotiKeep só salva notificações que chegam após a instalação e a concessão do acesso às notificações.

Quais versões do Android são suportadas?

Android 9.0 e superiores.

Quanto armazenamento o NotiKeep usa?

Notificações de texto são minúsculas — alguns MB cobrem meses. O espaço fica com as imagens: cada foto salva tem cerca de 20–80 KB. Um usuário pesado com 1.000 notificações com imagem por mês usa ~30–80 MB. Se preocupar, encurte o período de retenção.

O que acontece com meus dados se eu desinstalar?

Todos os dados do NotiKeep — notificações, imagens, preferências, favoritos — ficam no aparelho, então a desinstalação apaga. Para manter ao reinstalar ou mudar de celular, considere o backup com imagens e restauração (recurso Pro).

Que permissões o NotiKeep precisa?

Apenas acesso a notificações. Sem localização, sem contatos, sem outros acessos.

Posso exportar meus dados?

O Pro cria um ZIP com o banco de dados, imagens salvas, favoritos, listas de silenciados e configurações — tudo junto. Restaure em um celular novo em um passo. O local de salvamento é à sua escolha.

O que acontece no fim do teste de 30 dias?

Você volta para o Free. Sem renovação automática. Se quiser Pro, escolha um plano na tela de upgrade.

Vai gastar bateria ou deixar o celular lento?

O NotiKeep só trabalha quando uma notificação chega. Não fica consumindo bateria.

Onde meus dados ficam guardados?

Todos os dados ficam no aparelho. Os backups vão apenas para o caminho que você escolher.
