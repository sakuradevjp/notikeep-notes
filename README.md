## What is NotiKeep?

An Android app that saves every notification you ever receive — text and embedded images — so you can search and recall what fired weeks or months later. Ad-free. All data stays on-device.

- 📥 Saves text + images from every notification
- 🔍 Full-text search by app, sender, content
- 🔒 100% local — no cloud sync, no analytics
- 🌙 Dark theme, full-screen image gallery
- 🆓 Free with optional Pro upgrade

**Get it on Google Play**: https://play.google.com/store/apps/details?id=jp.sakuradev.notikeep
